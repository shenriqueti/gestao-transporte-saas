# 🚐 Minha Van - Gestão de Transporte Escolar

Sistema de gestão para motoristas de transporte escolar. Focado em agilidade, controle financeiro e uso no celular.

## 📱 Funcionalidades

### 1. Chamada Diária

- **Check-list Rápido:** Marque quem embarcou e desembarcou.
- **Resumo:** Contador de presentes em tempo real.
- **WhatsApp:** Botão direto para falar com o responsável.
- **Limpeza:** Botão para zerar a chamada do dia.

### 2. Gestão de Passageiros

- **Cadastro:** Nome, Escola, Turma, Professora e Mensalidade.
- **Contatos:** Suporte para 2 telefones.
- **Edição:** Altere os dados a qualquer momento.

### 3. Controle Financeiro

- **Visão Mensal:** Navegue entre os meses.
- **Status:** Controle visual de PAGO (Verde) e PENDENTE (Vermelho).
- **Vencimento:** Cada aluno com seu dia de vencimento.
- **Resumo:** Total Recebido vs Pendente calculado na hora.

## 🚀 Como Usar

1. Abra o link do sistema no seu celular.
2. Vá em **Alunos** e cadastre as crianças.
3. Na aba **Chamada**, faça o controle diário.
4. Na aba **Finanças**, marque quem já pagou o mês.
