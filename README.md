# Escolar Gestão SaaS 🚐

Micro SaaS de gestão para motoristas de transporte escolar. Focado em organização de rotas, controle de alunos e gestão financeira simplificada.

## 🚀 Funcionalidades Planejadas

**Gestão de Alunos:** Cadastro completo com informações de responsáveis e endereços.
**Controle Financeiro:** Status de mensalidades (Pago/Pendente).
**Checklist de Rota:** Embarque e desembarque em tempo real.

## 🛠️ Tecnologias

HTML5 / CSS3 (Design Responsivo)
JavaScript Vanilla
LocalStorage para persistência de dados (Trabalha Offline)
